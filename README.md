# dadadima/homebrew-tap

Homebrew formulae for my tools.

```bash
brew install dadadima/tap/bqtop      # htop for BigQuery: https://github.com/dadadima/bqtop
```

Formulae install the prebuilt single-file binaries attached to each GitHub release (macOS arm64 /
x86_64, Linux arm64 / x86_64). `Formula/bqtop.rb` is regenerated by bqtop's release workflow.
